# 项目执行入口

开始工作前读取已批准的审批单和 [协作配置](readme2machine/collaboration.md)，确认自己承担的角色。协调者按配置派发任务与安排审核；执行任务读取 [执行者说明](readme2machine/experiment-submitter/SKILL.md)，审核任务读取 [审核者说明](readme2machine/experiment-reviewer/SKILL.md)。角色名称不自动授予执行或批准权限。

本模板尚无批准。负责人批准的报告、目录、权限和实验协议是实际工作依据。未明确授权的实验不启动。原始观测不覆盖；重试新建运行 ID。

所有仓库提交遵循 [固定Git流程](readme2machine/git-workflow.md)：子代理继承最新主分支提交，主代理审核后用双父merge整合；禁止子代理直推主分支。
