# 报告契约草案

以下是待负责人选择/修改的候选主干，审批单批准后才成为本项目要求：

0. 元数据：实验 ID、版本、执行/证据/结论状态、机器入口。
1. 概述：问题、原因、假设和简要结果。
2. 原理与方案：干预、基线、适配和解释所需原理。
3. 设置与执行：样本/数据、对照、配方、顺序、重复、选点/停止规则。
4. 结果：原始事实、主要图表、异常与负结果。
5. 讨论：证据与解释、限制、外推边界。
6. 结论与复现：回答问题、下一步决策、材料与执行入口。

具体图表清单以审批单为准。图的数值能回查原始观测；图注可见，单位、分母、筛选和不确定性说明清楚。未观测指标不补造；单次实验不推断重复稳定性。
