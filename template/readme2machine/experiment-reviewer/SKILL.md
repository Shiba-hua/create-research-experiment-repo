# 审核与整合

先读已批准审批单、[协作配置](../collaboration.md)、报告契约、实验设计和完整提交材料。确认审核职责及整合权限，执行者不能为自己的提交签发批准。

冻结审阅版本；Git 模式冻结 source/target 完整 SHA，非 Git 模式冻结提交清单和文件身份。版本变化后重新审查受影响内容，不能拿新值替换旧批准记录来掩盖差异。

核查问题/对照与实际执行一致，输入/样品、协议、版本、配置、环境与原始观测可追溯；缺测、失败和排除计入约定分母。检查图表数值、可见图注和统计含义，实际查看图。材料检查不证明假设成立。

审核记录分别给出交付合规性、证据有效性和实验支持的结论，注明阅读材料、实际检查、发现的问题与处理。有效负结果可以合入；无效实验保留为明确的故障记录。超出自身专长的科学判断交给指定专家，不假装已完成领域审查。

由已授权角色按批准方式整合精确版本，记录批准依据和最终版本；如采用 Git，复核远端身份并避免覆盖其他提交。仓库文本规则不是已验证的平台访问控制。
