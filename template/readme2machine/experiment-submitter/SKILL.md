# 执行与提交

先读已批准审批单、报告契约和具体实验设计。模板尚未批准时，只能准备对齐材料。确认本次执行者、预算、工作范围及协作方式；设备操作遵守已批准 SOP，不能由此文件自行推导物理操作权限。

建立独立运行 ID，记录实际配置、输入/样品、执行版本、环境/校准、操作或命令和原始结果。重试不覆盖旧记录。正常完成与异常分别记录，按约定通知；原始观测不可为叙事美化而更改。

提交报告、按约定绘制的图及源数据/脚本、机器复现材料和缺口说明。失败与负结果可以交付，不能虚构未测项。执行获批的机械检查并保存实际输出；人类执行者可用等价清单交给协调 AI 录入。

按批准的 Git 分支或交接方式提交：写明精确版本、变更、检查和限制；不得自行批准或越权整合。Git 提交绑定 source/target SHA，审查期间任一变化应通知重新审核。移交后等待指定审核者，不通过切换 skill 自批。
