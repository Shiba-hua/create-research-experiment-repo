# 机器复现材料

每个 experiment ID 连接报告与 run ID。每次运行记录实际协议/配置、输入或样品身份、代码或 SOP 版本、依赖/仪器/校准、操作者、执行命令或操作顺序、时间边界、输出身份与可用性。记录的版本是执行时的版本，不是整理报告时的新版本。

软件通常用配置、命令数组、环境锁及源码身份；实体实验用样品批次、仪器设置、校准证书、逐步操作与原始仪器导出。按实际领域适配，不要求无意义的代码字段。

数据文件记录相对路径、大小、SHA256；不能公开的材料记录访问办法与缺口。重算分析另存，引用输入哈希和分析版本。恢复材料、复算已观测结果和新运行分别提供入口、预期检查与已验证范围。
